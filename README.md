# IT342_G5_Mantilla_Lab1
## Mini Inventory Management System

##  What is this?
A digital inventory management solution for small to medium businesses that replaces manual paper-based or spreadsheet tracking. The system consists of:
- **Android mobile app** - Staff can perform stock in/out operations on-the-go
- **Web dashboard** - Admins manage products, categories, and user accounts
- **Centralized database** - Real-time synchronization and transaction logging

##  Why does it exist?
Small businesses struggle with:
-  Errors from manual inventory tracking
-  No real-time visibility of stock levels
-  Difficulty tracking who made inventory changes
-  Poor decision-making for restocking

This system solves these problems by providing accurate, real-time inventory tracking with full accountability.
